The following examples use the mat-select component of Angular Material.
Data Source

Most common case is showing data from backend API and with mat-select this is extremely simple since you can bind directly to observable when using angular | async pipe.

select person @for (person of (people$ | async)!; track person.id) { {{ person.name }} } Selected: {{selectedPersonId}}

You can also set array of objects as items input.

select person @for (person of people; track person.id) { {{ person.name }} } Selected: {{selectedPersonId2}}

While array of objects is the most common items source, you may want to set simple array of strings, numbers, booleans.

select person @for (item of simpleItems; track item) { {{ item }} } Selected: {{selectedSimpleItem | json}}

If you have simple use case, you can omit items array and bind options directly in html using mat-option component.

Select car @for (car of cars; track car) { {{car.name}} } Custom Selected car ID: {{selectedCarId | json}}
